# refs/

References hand over a visual grammar in one go — pacing, type, transitions.
Naming a style works better than describing one; a frame or clip works better
than both.

- a single frame of a video you love
- a short clip (`node <skill>/scripts/reference.mjs refs/clip.mp4` → sheets, cuts, palette)
- a folder of your own past work — the library nobody else can copy

Take the grammar, never the subjects, logos or copy.
