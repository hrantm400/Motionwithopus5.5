# assets/

Only approved, real material goes here.

- `fonts/` — licensed font files (woff2/otf/ttf) loaded with `@font-face` from `src/`
- `screens/` — real product screenshots or frames from real screen recordings
- `audio/` — a supplied music track, plus its `beats.json` from `beats.py`
- `site/` — what `capture.mjs` pulled from the public website (review before use)
- logos as SVG where possible

A missing screen is a blocker: ask for it. Opus can invent a camera move; it
must never invent your dashboard, a feature or a metric.
